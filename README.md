# LNP Encapsulation Predictor

Machine learning project to predict lipid nanoparticle encapsulation efficiency from formulation characteristics.

## Objectives

- Explore public LNP datasets
- Build baseline ML models
- Predict encapsulation efficiency
- Analyze important formulation variables
- Deploy model through FastAPI
- Containerize with Docker

## Tech Stack

- Python
- Pandas
- Scikit-learn
- FastAPI
- Docker
- MLflow
